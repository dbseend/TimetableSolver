# 0007. 내 전공 학점 계산: 전공 유형 ≠ 내 전공, 사용자 확인 과목 목록 기준

- 상태: 채택(구조 구현), 학교 규칙 미확인 (2026-11-09)
- 관련 코드: `apps/web/src/features/major/{major.ts,MajorPanel.tsx}`, `features/catalog/{adapter.ts,presets.ts}`, `app/state.ts`, `app/App.tsx`
- 테스트: `apps/web/tests/unit/major.test.ts`, E2E "내 전공 최소 학점"

## 문제

포털 파일의 이수구분(전필·전선)은 **15개 개설 학부 전체**에 붙어 있다. 이전 구현은 '전공' 그룹 = 전필+전선으로 만들어
"전공 12학점 이상"이 다른 학부의 전공 과목까지 내 전공으로 셌다. 경고 문구만으로는 잘못된 계산을 막지 못한다.

## 학교 파일에서 확인한 사실(실데이터는 미커밋)

- 소속 정보는 `개설정보` 1번째 줄의 **개설 소속(학부 단위)**뿐이다(예: "AI컴퓨터전자 주간", 16종, 모두 "주간").
- 학과·전공 단위 열, 수강 대상 학과, 전공 인정 범위 열은 **없다**. `교양실무`(영어1·전공기초 등)는 교양 영역 표시다.
- 한 과목코드는 항상 한 개설 소속에만 속한다. 과목코드 접두(ECE, MEC…)는 개설 소속과 거의 1:1이다.
- 따라서 파일만으로 "이 학생에게 이 과목이 전공으로 인정되는가"는 알 수 없다.

## 결정

1. **전공 유형**과 **내 전공**을 분리한다.
   - 전공 유형: 사용자가 가져오기 화면에서 표시한 이수구분(포털 프리셋 기본값 전필·전선). `LoadedCatalog.majorTypeCategories`.
   - 내 전공: 사용자가 **과목 목록을 직접 확인**한 결과(`MajorDefinition.courseIds`). 개설 소속·전공 유형은 후보를 좁히는 보조 정보다.
2. 포털 프리셋은 '전공' 그룹을 자동으로 만들지 않는다. 개설 소속은 `ImportResult.courseOrgs`로 **로컬에만** 기록한다(서버 Catalog에 넣지 않음).
3. 확인 전에는 전공 유형을 직접 쓰는 `category_min`을 확인 단계에서 막는다(`majorConstraintProblem`). 다른 조건과 시간표 생성은 계속 사용할 수 있다.
4. 확인하면 해당 과목에 `내전공` category를 덧붙이고 `category_groups["내 전공"] = ["내전공"]`을 만든 Catalog를 서버 `/catalog/validate`로 다시 검증해 새 revision을 받는다. **API 계약 변경 없음.**
5. 확인 후에도 전필·전선을 직접 쓴 최소 학점 조건은 계속 막는다(학부 무관 계산이므로). `내 전공` 그룹으로 바꿔야 한다.
6. 기준을 지우면 `내전공`을 참조하는 조건도 함께 지운다(사라진 분류 참조로 서버 422가 나지 않도록).
7. 복수전공·부전공·타 학과 인정은 자동 판정하지 않는다. 사용자가 인정 과목만 남기는 방식으로 표현한다.

## 확장 구조(학교 규칙을 받으면)

```text
MajorRuleSet (로컬, 버전·출처 포함)
  program: { kind: primary|double|minor, name }
  include: [{ by: course_id | code_prefix | org, value, categories?: [...] }]
  exclude: [{ by: course_id, value }]
  source: "학교 교육과정표 2026" 등 출처 문자열, confirmedAt
→ 평가 결과는 항상 과목 ID 목록으로 펼친 뒤 사용자에게 보여 주고 확인받는다(규칙 결과를 조용히 적용하지 않음).
→ 프로그램이 여러 개면 category id를 `내전공:주전공`, `내전공:복수전공`처럼 나눠 각각 category_min을 건다.
```

## 사용자에게 필요한 정보(추측하지 않음)

1. 주전공의 정확한 명칭(학부/전공)과 학번(입학 연도) 기준 교육과정 — 전공 인정 과목표 또는 교육과정 문서가 있는지.
2. 복수전공·부전공 여부와 그 명칭.
3. 다른 학부가 개설한 과목이 전공으로 인정되는 경우의 규칙(예: 지정 과목 목록, 학부 공통 과목)과 출처.
4. 전필/전선 중 내 전공 최소 학점에 포함할 구분(현재 전필+전선을 전공 유형으로 사용자 확인).
