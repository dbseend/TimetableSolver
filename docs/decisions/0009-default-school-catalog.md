# 0009. 기본 학교 개설강좌 제공(로컬)과 배포 시 데이터 위치·공개 범위

- 상태: 로컬 기본 제공 **구현**(2026-11-09). 배포 방식은 **미결정**(아래 선택지).
- 관련: `apps/web/scripts/build-school-catalog.mjs`, `services/api/app/application/default_catalogs.py`, `GET /api/v1/catalogs`, `GET /api/v1/catalogs/{id}`, `apps/web/src/features/catalog/SchoolStart.tsx`

## 결정(로컬)

- 일반 사용자는 파일을 올리지 않는다. 첫 화면에서 **학기 선택 → 학교 강좌로 시작하기**.
- 관리자가 학기마다 포털 내보내기 파일을 변환한다:
  `node scripts/build-school-catalog.mjs <파일> --term 2026-2 --as-of 2026-11-09 --label "2026학년도 2학기"` (apps/web에서).
  화면 업로드와 **같은 변환 코드**(`importCatalog`, 포털 프리셋, 사용자 확인 교시표)를 쓴다.
- 결과 `<id>.catalog.json`(계약 Catalog)·`<id>.meta.json`(기준일·출처 파일명·교시표 근거·제외 사유·개설 소속)은 기본적으로 저장소의 `local-data/catalogs/`(Git 제외)에 둔다. 백엔드는 `CATALOG_DIR` 환경 변수로 위치를 바꿀 수 있고, 없으면 저장소 기준 상대 경로를 쓴다(절대경로 하드코딩 없음).
- 서버는 파일을 읽을 때 업로드와 **같은 검증**(Pydantic strict + 의미 검증 + revision 계산)을 하고, 실패한 파일은 목록에 `valid=false`로만 보이며 내려주지 않는다. 생성은 같은 `/solve`·같은 솔버.
- 이수내역은 여전히 브라우저 안에서만 처리한다(이 기능과 무관).
- 현재 기본 데이터: 2026-2학기, 기준일 2026-11-09(사용자 확인), 518과목·819분반 중 656분반 사용(제외: 시간 미정 153, 토요일 교시표 없음 10).
- 테스트·CI는 실데이터 대신 합성 기본 카탈로그 `fixtures/default-catalogs/`를 쓴다.

## 배포 시 결정할 것 (아직 하지 않음)

| 질문 | 선택지 | 권장(근거) |
|---|---|---|
| 데이터 저장 위치 | ① 백엔드 컨테이너 이미지에 포함 ② 백엔드 서버의 별도 볼륨/디렉터리(`CATALOG_DIR`) ③ 비공개 객체 저장소(S3 등)에서 기동 시 내려받기 ④ DB(main의 Supabase 안) | **② 또는 ③**: 학기마다 이미지 재빌드 없이 교체 가능, 저장소(Git)에 실데이터를 넣지 않음. ①은 이미지가 공개 레지스트리면 노출. ④는 P0 범위 밖이며 main의 공개 읽기 RLS(`using (true)`)는 그대로 쓰면 안 됨 |
| 저장소 공개 여부 | 실데이터 Git 커밋 | **커밋하지 않음**(현 상태 유지). 변환 결과도 `local-data/`(Git 제외) |
| 공개 범위 | 누가 API로 받을 수 있나 | 학교 구성원 대상이면 **학교 인증 뒤** 또는 최소한 공개 범위를 학교가 허락한 항목으로 제한. 확인 전 공개 배포 금지 |
| 공개해도 되는 항목 | 과목코드·과목명·분반·학점·이수구분·시간·강의실·개설 학부·교수명 | 교수명·강의실은 포털에서 학생에게 보이는 정보지만 **외부 공개 허용 여부는 학교 확인 필요**. 정원·수강인원·강의계획서 링크·비고는 현재 변환에서 쓰지 않으므로 보내지 않는다 |
| 최신성 | 기준일 표시·갱신 주기 | 메타에 `as_of`를 필수로 두고 화면에 표시(현재 구현). 수강 정정 기간에는 갱신 주기·마지막 갱신 시각을 안내 |
| 무결성 | 누가 변환·검증했나 | 메타에 출처 파일명·변환 시각·교시표 근거 기록(현재). 배포 시 변환 결과의 해시와 승인자 기록을 추가 권장 |

## 알려진 제한

- 변환 스크립트는 포털 내보내기 형식만 받는다(다른 형식은 화면의 '파일 직접 올리기'에서 열 매핑).
- 교시표 적용 학기·예외 규칙, 토요일 교시, 시간 미정 분반 수업방식은 미확인(제외 유지).
- 기준일은 사용자가 확인한 내려받은 날짜이며, 학교 시스템의 데이터 갱신 시각과 같다는 보장은 없다.
