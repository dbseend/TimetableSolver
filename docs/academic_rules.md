## 1. 시간 체계

| 항목 | 값 | 출처 | 현재 코드 가정 |
|---|---|---|---|
| 표기 방식 | **요일+교시**. 웹 표 `Mon1,Thu1`, 다운로드 `월1,목1 Mon1,Thu1`(영문 쪽은 잘려 있는 경우 있음 → 한글 기준) | S4, S6 | 시:분 (`HH:MM`) → 교시→시각 변환 필요 |
| 수업 단위 | 학점당 50분, 3학점은 75분 × 2회 | S1 제42조 | 합성: 50·75·100·165분 |
| 연강 | 같은 과목 연강은 가능한 한 피함(원칙) | S1 제42조 | – |
| 1교시 시작 | 08:30 → **09:00으로 30분 늦춤**, 이후 교시도 30분씩 이동. 시행 학기는 기사 안에서 "올해 2학기"/"26학년도 1학기"로 엇갈림 | S5 | 격자 시작 08:00 |
| 교시 → 시각 대응표 | `[사용자 확인 필요]` 수강신청 시스템에서 확인. 가설: 90분 간격(75분 수업 + 15분) → 1교시 09:00, 2교시 10:30, …, n교시 = 09:00 + (n−1)×90분 | 가설(검색 요약에 "08:30 시작, 10교시 22:00–23:15"라는 2022년 자료가 있었으나 원문 미확인) | – |
| 실제 사용 교시 | 1–10교시 모두 사용. 시간 없는 분반 131개(온라인·집중·현장실습 추정) | S6 | – |
| 마지막 교시 종료 | `[사용자 확인 필요]`. 가설대로면 9교시 21:00–22:15, 10교시 22:30–23:45 → 실데이터에서 13개 수업이 22:00 초과 | S6 | **격자 끝 22:00 → 부족** |
| 1학점(50분) 수업의 교시 표기 | `[사용자 확인 필요]` (같은 교시 시작, 50분 종료로 추정) | – | – |
| 수요일 채플 등 요일별 예외 | `[사용자 확인 필요]` | – | – |
| 토요일 수업 | **있음** (10개 분반, 교양·전선) | S6 | 월–금만 → 로더가 해당 행을 오류로 보고 |
| 공동체리더십훈련 시간 | 학부는 이 시간에 강의를 배정하지 않음. 요일·시각은 `[사용자 확인 필요]` | S1 제45조 | – |

> C5 영향: 입력이 교시제라 로더에 `교시 → (start, end)` 변환표가 필요하다. 마지막 교시가 22:00을 넘으면 `DAY_END_MIN`을 늘려야 한다. 75분 단위가 30분 격자에 딱 맞지 않아(09:00–10:15) 종료가 올림 처리된다.

## 6. 개설강좌 표 형식 (C2, S4에서 확인한 머리글)

```
구분 | 과목코드 | 분반 | 과목명 | 학점 | 교수 | 시간 | 강의실 | 정원 | 인원 | 영어 | 온라인 | 교양실무 | 성적유형 | PF병행 | 집중이수제 | 강의계획서 | 비고
```

| 열 | 예시 형식 | 내부 스키마 대응 |
|---|---|---|
| 구분 | `전선` (이수구분 약칭) | `Course.category` |
| 과목코드 + 분반 | `ECE10002` + `01` | `Course.id`, `Section.id = 코드-분반` |
| 과목명, 학점 | 문자열, 정수(0.5 가능성 `[사용자 확인 필요]`) | `Course.name`, `Course.credit` (현재 int) |
| 교수 | 이름 | `Section.instructor` (실데이터는 커밋 금지) |
| 시간 | `Mon1,Thu1` / `Tue6,Tue7` | `Section.meetings` ← 교시표로 변환. 연속 교시는 한 블록으로 병합 |
| 정원, 인원 | 정수 | `Section.capacity` |
| 영어, 온라인 | `0%`, `10%` | 미사용 (필터 후보) |

- 조회는 학부를 하나 골라야 결과가 나온다(전체 선택 시 빈 결과).
- 전체 다운로드(`.xls`)는 실제로는 CP949 HTML 표다. 머리글이 `구 분`, `분 반`, `과목명 (CourseName)`, `시간 (Period)`처럼 공백·영문 병기이고, `교수` 대신 `개설정보` = `<개설학부> 주간<교수>[외 N명]`.
- 로더: `backend/app/loaders/hisnet.py` (`parse` = 웹 표 붙여넣기, `parse_export` = 다운로드 파일). CLI: `python scripts/import_hisnet.py <in.tsv|in.xls> <out.json>`.
- 변환 결과(S6): 819행 → 과목 507, 분반 784. 거부 35행 = 토요일 10 + 0.5학점 8 + 분반 간 학점/구분 불일치 17.
