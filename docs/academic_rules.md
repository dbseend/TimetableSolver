# 학사 규칙 (C3) — 사용자 확인 필요

이 문서는 **빈칸 템플릿**이다. 추측으로 채우지 않는다. 각 항목의 `[사용자 확인 필요]`를 공개 학칙·학사 공지·수강신청 화면에서 확인해 채우고, 확인한 출처(문서명·날짜, URL은 공개 페이지만)를 적는다.
채운 값은 C5(스키마 확정)에서 `backend/app/core/time_slots.py`, 모델, `docs/API.md`에 반영한다.
